# Aydın Parlamento Atlası

1950–2026 arasında TBMM genel kurul konuşmalarında Aydın'ın yöresel sorunlarının (tarım, çevre, enerji, deprem vb.) nasıl konuşulduğunu gösteren etkileşimli web sitesi. TÜBİTAK 2204-A "TBMM Tutanaklarında Aydın'ın Yöresel Sorunları: 1950–2026 Metin Madenciliği Analizi" projesinin somut ürünüdür.

- Site: tek dosyalık statik sayfa (`index.html`); veriler sayfanın içine gömülüdür, `data/` klasöründe aynı veriler JSON olarak da bulunur.
- Veri: 1950–Nisan 2023 için Demirtaş (2026) Zenodo TBMM genel kurul derlemi (CC BY 4.0); 2023–2026 için TBMM web sitesindeki 28. dönem tutanakları. Burada yalnızca özet oranlar, ayırt edici kelimeler ve seçilmiş alıntılar yer alır, ham tutanak metni yoktur.
- Alıntılar tutanak metniyle birebir karşılaştırılmıştır. Bir alıntı vekilin kendi görüşü olmayabilir; bağlam notları bunu belirtir.
- Sınırlılıklar: 1950'ler ve 1970'lerde kelime sayısı azdır; hipotezler veri görüldükten sonra kurulmuştur; 1923–1950 kapsam dışıdır; sonuçlar nedensellik iddia etmez.

Veri CC BY 4.0 koşullarıyla paylaşılır; kaynak olarak Demirtaş (2026) ve TBMM tutanakları gösterilmelidir.
